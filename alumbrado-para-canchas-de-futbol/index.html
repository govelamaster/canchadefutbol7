07 / Preguntas frecuentes

Antes de cotizar tu alumbrado.

¿Sirve para futbol 7, soccer y futbol rapido?

Si. Diseñamos la configuracion segun medidas, deporte, altura disponible, cantidad de postes, potencia LED y nivel de uso nocturno.

¿Incluye instalacion?

La propuesta puede incluir suministro, bases, cableado, conexiones, orientacion luminica e instalacion profesional, segun alcance y ubicacion del proyecto.

¿Pueden iluminar una cancha ya existente?

Si. Se revisan medidas, accesos, punto electrico, estructura existente y condiciones de obra para definir la mejor solucion.

¿Que necesito para cotizar?

Medidas de la cancha, ubicacion, fotos o video del espacio, tipo de uso y si ya cuenta con acometida electrica o bases para postes.

¿Que lamparas se recomiendan para canchas de futbol?

Usamos reflectores LED deportivos con potencia, optica y angulo calculados para cubrir el campo sin dejar zonas oscuras. La configuracion depende de medidas, altura de postes y uso nocturno.

¿Tambien iluminan tenis, basquetbol, gimnasios o estadios?

Si. Adaptamos el sistema para canchas multiusos, tenis, basquetbol, gimnasios, campos deportivos y proyectos tipo estadio, cuidando uniformidad, deslumbramiento y experiencia visual.
